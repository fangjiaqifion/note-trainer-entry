# Note Trainer

[Open Note Trainer](https://fangjiaqifion.github.io/note-trainer-entry/)

## Release progress

Updated November 25, 2026.

- The new entry requires cloud authorization to load practice. Teachers can enroll
  with an invitation, and students can activate an individual account.
- Teachers can create student profiles and issue one-use activation codes.
  Practice records and progress synchronize to the existing cloud service.
- Administrators use a separate sign-in with two-factor authentication to
  manage class entitlements, student seats, and access.
- Teacher, student, and administrator sign-in share the same visual style.

This repository contains the public entry. The practice release is delivered
by the authorization service. The former public entry is still available
while the cutover is being verified.
