# Note Trainer Entry

Note Trainer is a music-reading practice tool for invited teachers and their
students. This repository publishes the account entry and administration pages.

[Open Note Trainer](https://fangjiaqifion.github.io/note-trainer-entry/)

## Access

- Teachers register with an invitation or sign in with their teacher credentials.
- Students use a personal activation code issued by their teacher.
- Administrators use the separate sign-in with multifactor authentication.

After cloud authorization, teachers can manage their own class and students can
practice in their own profiles. Progress and practice records synchronize to the
cloud. The playable release and classroom records are served through the
authorization service and are outside this repository.

## Indexing and automated access

Please do not index, crawl, scrape, or mirror this repository or its Pages site.
The Pages HTML requests `noindex, nofollow, noarchive`. The repository is publicly
readable so GitHub Pages can serve the entry. The request depends on crawler
cooperation, and GitHub controls indexing on github.com. Use the direct link
provided by your teacher or administrator.
